# Resume Workflow

## Source Files

- `00 Career Evidence Bank.md`: career-wide facts, metrics, and evidence rules
- `David_Gordhamer_Master_Resume.md`: current master resume draft
- `02 Fintive Evidence.md`: detailed Fintive accomplishment pool
- Add one evidence dossier per earlier employer
- Store generated applications in `Tailored/`

## Tailoring Prompt

Read the career evidence bank, the master resume, and the employer evidence files relevant to the target role. Then create a tailored resume for the job posting below.

Use only supported facts. Do not invent metrics, technologies, titles, dates, user counts, or business outcomes. Prefer measurable outcomes when documented. Select the most relevant accomplishments for the posting, preserve chronological accuracy, and avoid repeating the same claim in multiple bullets.

After the resume, provide a short evidence audit listing the source file used for each selected accomplishment and identifying any claims that still need confirmation.

## Tailored Output Naming

Use:

`Tailored/<Company> - <Role> - YYYY-MM-DD.md`

Store generated tailored versions in the private applications repository, not in the public resume repository. Keep the source files unchanged when generating a tailored version.
